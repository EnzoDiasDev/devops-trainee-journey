# 📚 Próximas aulas

Aulas para depois da aula relâmpago. Termine a relâmpago, use o Git no dia a dia por alguns dias e
avise o Claude: **"bora para o próximo módulo de git"**.

| Módulo | Tema | Status |
|--------|------|--------|
| 1 | Reescrevendo a história com segurança: `reset`, `rebase`, `cherry-pick`, `reflog` (o "desfazer de emergência") | 🔒 em breve |
| 2 | GitLab na prática: Merge Requests, revisão de código, proteção da `main` | 🔒 em breve |
| 3 | Versões e entregas: `tag`, versionamento semântico, changelog | 🔒 em breve |
| 4 | Fluxos de trabalho em equipe: GitFlow × trunk-based, convenção de commits | 🔒 em breve |
| 5 | Git + DevOps: `.gitlab-ci.yml`, pipeline que roda a cada push | 🔒 em breve |

> Os temas podem mudar conforme a sua necessidade no trabalho. É só pedir.
