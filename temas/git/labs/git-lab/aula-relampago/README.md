# ⚡ Aula relâmpago — Git em uma tarde

Objetivo: em **~4 horas**, você sai usando o Git do dia a dia com confiança: salvar versões, ver o que mudou,
desfazer erros, trabalhar em branches, resolver conflitos e sincronizar com um servidor (como o seu GitLab).

| Bloco | Assunto | Comandos novos | Tempo |
|-------|---------|----------------|-------|
| [00](00-preparacao.md) | O que é Git + configurar | `git --version`, `git config` | 15 min |
| [01](01-primeiro-repositorio.md) | Salvar versões (commits) | `init`, `status`, `add`, `commit`, `log` | 30 min |
| [02](02-ver-mudancas.md) | Ver o que mudou | `diff`, `diff --staged`, `show` | 20 min |
| [03](03-desfazer.md) | Desfazer coisas (sem pânico) | `restore`, `restore --staged`, `commit --amend`, `revert`, `.gitignore` | 30 min |
| [04](04-branches.md) | Branches: trabalhar sem atrapalhar | `branch`, `switch`, `merge`, `log --graph` | 30 min |
| [05](05-conflitos.md) | Conflitos: quando duas mudanças brigam | resolver conflito, `merge --abort` | 25 min |
| [06](06-remoto.md) | Servidor: enviar e receber | `clone`, `remote`, `push`, `pull`, `fetch` | 35 min |
| [07](07-dia-a-dia.md) | O fluxo de trabalho real | `stash`, branch + push + Merge Request | 25 min |
| [08](08-desafio-final.md) | Desafio final + prova relâmpago | (nada novo) | 40 min |

## Como estudar cada bloco
1. **📖 Aprenda**: o comando explicado pedaço por pedaço.
2. **✍️ Pratique**: exercícios que usam **só** o que já foi explicado.
3. **🧠 Memorize**: perguntas rápidas. Responda **sem olhar** antes de abrir a resposta.

## Onde trabalhar
Tudo acontece dentro de **`aula-relampago/pratica/`**. Você vai criar repositórios de treino ali e pode
apagar tudo no final. Nada aqui mexe nos seus projetos de verdade.
