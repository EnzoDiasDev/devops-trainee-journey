# 🌿 Git Lab

> 📖 **Sobre este lab:** material de estudo que montei com apoio do Claude (assistente de IA), em formato de aulas. Menções a "avisar o Claude" vêm desse fluxo de estudo; você pode ignorá-las.
>
> **Pré-requisitos:**
> - **Aula relâmpago:** só Git instalado. Funciona offline.
> - **Treino Git + Docker (`treino-java`):** além do Git, precisa de **Docker** e de um servidor **GitLab** com um projeto vazio seu (pode ser o `gitlab.com` ou uma instância própria). Nos exemplos, o endereço aparece como `gitlab.example.com`; use o do seu GitLab. Antes, rode o [`preparar-imagens.sh` do Docker Lab](../../../docker/labs/docker-lab/preparar-imagens.sh) para criar as imagens usadas pelos scripts.

Aprender Git **fazendo**, no mesmo formato do Docker Lab: cada aula ensina **tudo** o que vai cobrar,
e só depois pede para você praticar.

| Divisão | Para quê | Status |
|---------|----------|--------|
| [⚡ Aula relâmpago](aula-relampago/README.md) | Ficar fluente no Git do dia a dia **em uma tarde** (~4 h) | ✅ disponível |
| [🦊 Treino Git + Docker no GitLab (Enzo Bank)](treino-java/README.md) | **Repetir o fluxo do dia a dia** no seu GitLab: Issues, MRs, revisão, branch protegida, pipeline, uma API Java em Docker e deploy | ✅ disponível |
| [📚 Próximas aulas](proximas-aulas/README.md) | Aprofundar depois: rebase, reset, tags, GitLab, CI... | 🔒 em breve |

## 📌 Combinados
- **Comandos** aparecem com `$` na frente. **Não digite o `$`.**
- **Digite** os comandos em vez de copiar e colar: é assim que memoriza.
- As respostas ficam escondidas em blocos **👀 Ver resposta**. Abra os `.md` no VS Code com `Ctrl + Shift + V`
  para ver formatado.
- O Git escreve as mensagens **em inglês**. As aulas traduzem as mais importantes.
