# API

> **Status:** 🟡 Em andamento

**O que é:** as APIs são o jeito como sistemas conversam entre si. Esse tema explica a conversa (requisição e resposta), o padrão REST, autenticação, paginação, limites de uso e webhooks.

## Por onde começar

Leia na ordem:

| # | Nota | O que você aprende | Nível |
|---|---|---|---|
| 1 | [Parte 1: o básico](api1.md) | O que é uma API, requisição × resposta, métodos HTTP, códigos de status, dois testes com `curl` | Iniciante |
| 2 | [Parte 2: intermediário](api2.md) | REST, parâmetros, idempotência, autenticação (API key, Bearer, OAuth, JWT), paginação, *rate limit*, versionamento, webhooks | Intermediário |

## Para praticar

Com um terminal e o `curl` você já consegue repetir os exemplos da Parte 1 (a API pública do GitHub não exige cadastro).
