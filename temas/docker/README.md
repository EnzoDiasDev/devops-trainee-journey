# Docker

> **Status:** 🟡 Em andamento

**O que é:** o Docker empacota um programa e tudo o que ele precisa num **contêiner**, que roda igual em qualquer máquina.

## Conteúdo

O estudo é feito num [**Docker Lab**](labs/docker-lab/README.md): cinco níveis curtos, cada um ensina antes de pedir para praticar.

| Nível | Tema |
|---|---|
| 1 | [Primeiros passos](labs/docker-lab/nivel-1/README.md): rodar, listar, parar, apagar e entrar em contêineres |
| 2 | [Criar imagens](labs/docker-lab/nivel-2/README.md) com Dockerfile |
| 3 | [Guardar dados](labs/docker-lab/nivel-3/README.md) com volumes |
| 4 | [Contêineres conversando](labs/docker-lab/nivel-4/README.md) (redes) |
| 5 | [Vários contêineres juntos](labs/docker-lab/nivel-5/README.md) com Docker Compose |

## Antes de começar

Tenha o Docker instalado e rode, uma vez, o script que prepara as imagens usadas nos exercícios:

```bash
cd temas/docker/labs/docker-lab
bash preparar-imagens.sh
```

Detalhes na [página do lab](labs/docker-lab/README.md).
